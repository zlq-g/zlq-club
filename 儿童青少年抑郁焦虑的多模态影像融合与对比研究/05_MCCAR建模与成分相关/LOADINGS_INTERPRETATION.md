# Loading 相关矩阵的含义

`A{k}` 的维度是「被试 × 成分」。一列代表该模态某个成分在所有被试中的表达得分。空间成分 `ccacomp{k}` 为「成分 × 特征」，满足近似重建关系：

```matlab
data{k} approximately equals A{k} * ccacomp{k}
```

空间图展示模式在哪里，loading 表示每个被试对该模式的表达。成分整体符号可以翻转，解释得分方向时应结合空间图符号。

## 矩阵计算与排列

```matlab
Am = cat(2, A{:});
loading_corr = corr(Am, Am, 'rows', 'complete');
imagesc(abs(loading_corr), [0, 1]);
```

默认排列为 fMRI、dMRI、sMRI。若 M=100，则三个模态分别占索引 1-100、101-200、201-300，形成 300×300 矩阵。每个元素是两列被试得分的 Pearson 相关。矩阵包含九个分块：三个模态内相关分块和六个跨模态相关分块（上下三角互为转置）。

例如 `(1,101)` 是 fMRI 成分1与 dMRI 成分1的得分相关；`(1,102)` 是 fMRI 成分1与 dMRI 成分2的相关。

## 亮线代表什么

- 黄色主对角线是每个成分与自身相关，理论值为 1，不是模型有效性的证据。
- 模态内分块的非对角线较暗，表示不同成分得分的线性相关较弱，与白化及模型约束有关；不等于统计独立。
- 跨模态分块中的亮斜线表示同编号成分之间相关通常较强，符合模型优化跨模态关联的目标，但不能仅凭斜线确认生物学同源性。
- 颜色编码 abs(r)，r=0.8 与 r=-0.8 颜色相同。带符号矩阵保存在结果 MAT 中。这是热图，不是按圆点面积编码的气泡图。

## 与其他分析区分

此图计算跨被试成分得分相关，不是脑图空间相似度，不是脑区连接矩阵，也不是与临床变量的相关图。与参考变量相关是另一步：

```matlab
[r, p] = corr(A{k}, Ref, 'rows', 'complete');
```

跨模态相关是训练目标的一部分。高训练相关不能代替独立测试，也不能直接说明因果关系或跨年龄组复现性。不同运行之间的成分编号还需匹配，不能自动视为同一个成分。
